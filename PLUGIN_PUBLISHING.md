## Full Description

**Token Link** automates Figma variable aliasing using rule-based automation. Stop manually creating aliases between collections—define rules once and apply them across your entire design system.

### Key Features

- **Rule-Based Aliasing**: Define rules to automatically create aliases between variables based on collection, group, and mode patterns
- **Dry-Run Preview**: Test rules before applying to see exactly what changes will be made
- **Batch Operations**: Apply rules to hundreds of variables at once
- **Export & Import**: Save and share rule configurations as JSON
- **Visual Feedback**: See evaluation results and warnings before applying changes

### Perfect For

- Design system teams managing large variable sets
- Design ops teams automating token workflows
- Teams working with multiple collections (Primitives, Semantic, Interaction, Brand)
- Anyone tired of manually aliasing variables

### How It Works

1. Define rules matching variables by collection, group, or mode
2. Preview changes with dry-run mode
3. Apply rules to automatically create aliases in Figma
4. Export rules to share or backup

Stop wasting time on manual aliasing. Start automating your Figma variables today.
